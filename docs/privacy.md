# CodeBuddy Student Privacy & Data Retention Policy

## 1. Student Data Collected
- **Profile Information**: Name, email, college, degree, year, programming preferences, target companies.
- **Learning Behavior Data**: Assessment quiz responses, submitted source code, runtime performance metrics, hint requests, post-submission understanding answers, mistake history.

## 2. Data Usage & Confidentiality
- **No Selling of Data**: Student interaction data is strictly used for personalized learning recommendations, skill classification, and platform analytics.
- **Camera / Microphone Consent**: Web camera and microphone access during Company Mock Interview sessions are strictly processed for local video preview and integrity monitoring. No raw video files are recorded or stored on remote servers without explicit consent.
- **Account Deletion**: Students can request full account deletion via Settings, removing their user profile, submission history, mistake memory, and notifications.
